# Saira Asua

**Diseño páginas web usando inteligencia artificial como método de trabajo principal.**

No como apoyo ocasional — como proceso completo: desde la idea hasta el código funcionando.

---

## Qué hago

Diseño y desarrollo sitios web para proyectos reales trabajando 100% con IA.
Cada proyecto que ves acá fue construido orquestando agentes, prompts y herramientas de IA en lugar de escribir código a mano.

**Tipos de proyectos:**
- Sitios web de producto y marca personal
- Herramientas web con lógica de negocio
- Sistemas con integración de bots y automatización
